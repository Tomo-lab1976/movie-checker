## Renderで公開
1. GitHubで新しいリポジトリを作成
2. このフォルダ内のファイルをアップロード
3. Renderで New > Web Service
4. GitHubのリポジトリを選択
5. `render.yaml` があるため設定を合わせやすい
6. Build: `pip install -r requirements.txt`
7. Start: `gunicorn app:app`

## 重要
