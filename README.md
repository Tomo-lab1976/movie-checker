# 🎬 Movie Checker v1.0

TOHOシネマズ八千代緑が丘とイオンシネマ幕張新都心の上映情報を、
同じ時間軸で比較して確認するためのWebアプリです。

「今から映画を観るなら、どちらの映画館で何が観られるか？」を
ひと目で確認できることを目的に作成しました。

## 対象映画館

- TOHOシネマズ 八千代緑が丘
- イオンシネマ 幕張新都心

## 主な機能

- 2館の上映スケジュールを同じ時間軸で横並び表示
- 今日から数日先まで日付を切り替えて表示
- 上映の開始時刻 → 終了時刻を表示
- 同じ映画は2館で同じ色にして比較
- 今日を開いたとき現在時刻付近へ自動スクロール
- 「現在時刻へ」ボタンで現在の上映時間帯へ移動
- 開始時刻を過ぎた上映を薄く表示
- TOHO公式の空席状況を表示
- イオン公式の空席状況を表示
- イオンは取得できる場合、残席数／総座席数も表示
- 映画を押すと上映時間・映画館・スクリーン・座席情報などを詳細表示

## 画面の考え方

映画館ごとに上映作品を一覧にするのではなく、
「時間」を基準にして2館を左右に並べています。

これにより、

「18時ごろなら何が観られる？」
「TOHOとイオンではどちらが空いている？」
「この映画は何時に終わる？」

といったことを、一つの画面で確認できます。

## 空席表示

### TOHOシネマズ

TOHO公式の空席情報を取得し、
公式サイトの表示に合わせて空席状況を表示します。

### イオンシネマ

イオン公式の上映・座席情報から空席状況を取得します。

取得できる上映については、

- 空席状況
- 残席数
- 総座席数
- スクリーン

などを詳細画面で確認できます。

## システム構成

- GitHub  
  プログラムの保存・変更履歴を管理

- Render  
  Webアプリをインターネット上で実行・公開

- app.py  
  Pythonで映画館の上映情報・空席情報を取得して整理

- static/index.html  
  ブラウザに表示する画面を担当

- JSON  
  app.pyで取得・整理した情報を画面側へ渡すデータ形式

大まかな流れは、

GitHub → Render → Python（app.py）→ JSON → Web画面

となっています。

## メンテナンス

映画館公式サイトの情報を利用しているため、
映画館側のWebサイトやデータ形式が変更されると、
上映情報や空席情報を取得できなくなる可能性があります。

動かなくなった場合は、

1. Renderが正常に動いているか確認
2. `/health` でアプリの稼働を確認
3. GitHubの変更履歴（Commit）を確認
4. 映画館側の情報取得方法が変わっていないか調査

という順番で確認します。

開発途中で使用した診断コードはv1.0では整理していますが、
それまでの変更内容はGitHubのCommit履歴から確認できます。
