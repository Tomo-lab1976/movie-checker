# 映画チェック 公開準備版

## 対象
- TOHOシネマズ 八千代緑が丘
- イオンシネマ幕張新都心

## 画面
- 今日〜7日間
- 2館を同じ時間軸に表示
- 座席状況は今日・明日だけ追加する想定

## Renderで公開
1. GitHubで新しいリポジトリを作成
2. このフォルダ内のファイルをアップロード
3. Renderで New > Web Service
4. GitHubのリポジトリを選択
5. `render.yaml` があるため設定を合わせやすい
6. Build: `pip install -r requirements.txt`
7. Start: `gunicorn app:app`

## 重要
映画館の公式サイトはHTML構造が変更されることがあります。
現在は公開ページを読み取る「取得部分」を分離してあるので、
変更時は app.py の `toho()` / `aeon()` を修正すれば画面側はそのまま使えます。

空席状況は次段階です。まず上映時刻が安定して取れることを優先します。


# Movie Checker

TOHOシネマズ八千代緑が丘とイオンシネマ幕張新都心の上映情報を、
同じ時間軸で比較するために作ったWebアプリ。

## 主な機能
- 2館の上映スケジュールを横並び表示
- 開始時刻 → 終了時刻を表示
- 同じ映画を同じ色で表示
- 現在時刻付近へ自動スクロール
- 開始済み上映を薄く表示
- TOHO公式の空席状況を表示
- イオン公式の空席状況・残席数を表示
- 映画を押すとスクリーン・座席情報などを表示

## 構成
- GitHub：プログラムの保存・変更履歴
- Render：Webアプリを実行・公開
- app.py：Pythonによる情報取得・整理
- static/index.html：画面表示
- JSON：app.pyと画面の間でデータを受け渡す形式
